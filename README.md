# TA Recall

帮助技术美术求职者复习面试知识的本地优先网页应用。题库、复习记录与个人笔记均保存在浏览器本地，无后端、无登录。

## 已实现功能

- **题库浏览**：分类筛选、标签筛选、关键词搜索、题目详情（内置 18 道示例题，覆盖 7 个分类）
- **题目管理**：新增/编辑共用表单（分类选择、标签增删去重、保存前校验）；编辑保持 id 不变，不影响复习记录与笔记
- **复习卡片**：先题后答，四档掌握度评分（不会/模糊/基本掌握/熟练）；个人笔记在"显示答案"后可折叠查看（编辑在详情页）
- **今日复习**：按优先级出题（不会 → 模糊 → 到期 → 从未复习），基本掌握 7 天、熟练 30 天到期
- **错题本**：汇总"不会/模糊"的题目，可重新复习（改判为基本掌握/熟练后自动移出）
- **追问体系**：追问是完整题目，支持新建、关联已有、解除关联；旧文本追问可"转为题目"或移除（移除需二次确认）
- **归档管理**：不提供永久删除，题目可归档（默认不出现在题库/复习/今日复习/错题本），在数据管理页搜索、查看与恢复
- **数据管理**：题库 JSON 按 id 合并导入（全量校验 + 原子应用 + 五类变更预览：新增/更新/无变化/将归档/将恢复）、导出题库、导出复习记录

## 数据存储

- 复习记录（`ta-recall.review-records`）、个人笔记（`ta-recall.personal-notes`）与导入合并后的题库（`ta-recall.question-bank`）保存在浏览器 localStorage，关闭页面后保留
- 题库以内置 JSON 为种子，导入或表单修改后以 localStorage 中的内容为准
- 本地存储访问统一经由 `src/data/questionStore.ts` 数据层

## 技术栈

React + TypeScript + Vite + Vitest，样式使用普通 CSS。

npm install
npm run dev    # 启动开发服务器
```

npm run lint    # ESLint
npm run test    # Vitest（单次运行）
npm run build   # 类型检查 + 构建
```
