# TA Recall 产品需求

## 1. 用户目标

用户正在准备技术美术实习面试，希望：

- 系统整理零散的图形学和引擎知识
- 反复复习不会的问题
- 针对个人作品集准备项目追问
- 练习 30 秒口述回答
- 查看每个答案的资料来源

## 2. 第一版功能

### 2.1 题库浏览

分类：

- 图形学基础
- Shader 与渲染
- Unity
- 性能优化
- 数学与编程
- 作品集追问
- 综合场景题

支持：

- 分类筛选
- 标签筛选
- 关键词搜索
- 查看题目详情

### 2.2 复习卡片

初始只显示题目。

点击“显示答案”后展示：

- 30 秒简答
- 回答关键词
- 详细解释
- 常见追问
- 相关项目
- 资料来源

复习完成后选择：

- 不会
- 模糊
- 基本掌握
- 熟练

### 2.3 今日复习

优先级：

1. 不会
2. 模糊
3. 到期需要复习
4. 从未复习

显示：

- 今日题目数
- 已完成数量
- 剩余数量

### 2.4 错题本

汇总“不​​会”和“模糊”的题目，并支持重新复习。

### 2.5 数据功能

- 从 JSON 导入题库
- 导出题库
- 导出复习记录
- 无效 JSON 应显示清晰错误，不覆盖原数据

## 3. 暂不开发

- AI 自动出题
- AI 回答评分
- 登录和云同步
- 多用户
- 社区和排行榜
- 语音识别
- RAG 知识库

## 4. 数据结构

每道题至少包含：

- id
- category
- title
- difficulty
- shortAnswer
- keyPoints
- explanation
- followUps
- relatedProjects
- tags
- sources
- reviewStatus

## 5. 第一版验收标准

- 可以浏览至少 12 道示例题
- 可以搜索和分类筛选
- 可以翻开答案
- 可以记录掌握度
- 关闭网页后记录仍然存在
- 可以浏览错题
- 可以导入和导出 JSON
- lint、test、build 全部通过
